# Nature in SAP

Restart SAP to load the native Tkinter companion in the lower-right corner. Drag the Nature title area or character to reposition the companion within SAP. The minus button folds it into a small neumorphic face circle at the bottom-right. Click the circle (or focus it and press Enter/Space) to restore the previous position and conversation. Dragging the character does not open the question box; a click still does. Hover offers onboarding when idle; clicking opens a question box. Questions switch to AI Agent, submit in Conversation Only mode, and display Thinking until the planner response arrives. Existing hardware execution confirmation remains in AI Agent.

The first route is AutoFocus → FocusMap → ImgStitch → LayoutMap → AutoTest (one device) → AutoTest (device list). Native page IDs, completion keys and descriptions live in `GUIDE` in `src/semi_auto_probe/ui/nature.py`. Navigation only changes pages; users review parameters and run operations themselves. The companion observes results on Tk's UI thread and defers feedback/navigation until active motion and workflows finish. Layout fitting uses its explicit success/failure callback; autofocus uses its usable-result flag. Cancellation does not celebrate. An AutoTest run that completes exactly one point satisfies the single-device step; wire-bond mapping uses its completed count. Already-completed prerequisites are not automatically skipped in this first route.

Nature sits while prompting and guiding, rests after ten seconds of eligible idle time, and uses the approved transitions and eight-frame moves. Assets and the v5 manifest are packaged under `src/semi_auto_probe/assets/nature`; the browser previews remain design references.

Validation: six Nature tests cover packaged frame rendering, explicit result semantics, ordered guide/retry behavior, idle/wake gating, minimization, and safe question submission. A hidden full SAP startup with camera and serial startup mocked initialized Nature and navigated to AutoFocus. The existing AgentPanel suite has eight Tk teardown errors (`can't delete Tcl command`) in this environment; the identical errors were reproduced with the unmodified HEAD version of AgentPanel. Hardware operation and a live remote AI response have not been exercised.

Next refinements: finer per-control guidance, saved onboarding preference, optional steps for alternate measurement modes, and more precise pointing directions. This revision routes by page and uses completion evidence rather than interpreting arbitrary status messages.


Guide refinement: AutoFocus first explains manual coarse focus with Z− / Z+ until the device outline is discernible. After FocusMap, Nature asks whether to record the full pre-test die surface. Record surface opens ImgStitch; Skip stitching goes directly to LayoutMap. Stitching is explicitly optional for electrical testing. The single-device stage points to Instrument in the top bar and offers Open Instrument; the subsequent batch stage uses AutoTest. Tests cover both stitching branches and the Instrument shortcut.


Step Detail scaffold: step overviews offer Step Detail before Next Step, plus End Guide. The per-instance step_details mapping is intentionally empty until the detailed control sequences are specified. Each future operation entry is a list of (instruction, resolver returning a live Tk widget) pairs. Step Detail preserves the parent guide stage and provides Continue, Back to Step and End Guide. GuideHighlight draws a rounded accent outline in a transparent owned window without replacing the target command or moving keyboard focus. It tracks widget geometry and hides while the companion is folded or SAP is minimized. New prompts clear the previous highlight. Tests exercise placeholder/return behavior and registered-target progression/cleanup without executing controls.


Detailed walkthroughs are now configured in `src/semi_auto_probe/ui/nature_walkthrough.py`. AutoFocus: Z−/Z+ together, then Start Auto; failure returns to Z adjustment. FocusMap: Generate Mesh, Start FocusMap. Optional stitching: Rows/Cols together, FocusMap plane Z toggle, Start. LayoutMap: Load GDS, Top cell, alternating GDS and Stage picks for P1 through P4, Fit / Update Mapping. AutoTest: Origin/vi/vj Pick, Collapse, Config Measure Flow, then Run AutoTest after the editor closes. Already-collapsed wobble settings skip the collapse instruction. Calibration points expand for their detailed sequence. Next Step advances within the detail sequence; the final Next Step proceeds to the next guide stage without invoking hardware. The single-device Instrument step retains its overview and shortcut pending detailed instructions.

Highlights support simultaneous controls and follow sidebar scrolling. The measurement-flow step waits until the actual editor has opened and closed before proceeding. AutoFocus and stitching overviews are each limited to two rendered lines at the configured font/wrap width. Validation: 22 Nature tests pass, plus all 26 target references resolved in a hidden real SAP startup with camera and serial disabled. Live hardware has not been exercised.


Prompt layout refresh: the panel uses one font-scaled width across every overview, detailed step and chat prompt. Three action columns fit their complete labels; four-action prompts put the extra action on a separate full-width row. Controls are ordinary child windows positioned over the rounded surface rather than a Canvas window item. Changes coalesce into one idle layout pass: constrain width, measure the final content height, resize the surface/window, then invalidate the layered window and its descendants after geometry settles on Windows. The character's default top anchor reserves 240 pixels below its 174-pixel canvas, so prompts grow down without moving the character; drag placement reserves the same space and is clamped within SAP. The single-device overview is also two lines. Regression tests repeatedly switch short/long/detail/four-button/help prompts, verify complete button bounds and surface sizes, and check the fixed character anchor and lower edge. All 24 Nature tests pass.
